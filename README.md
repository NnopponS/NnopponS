## Selected work

**01 / WheelSense & EaseAI** · Assistive technology  
WheelSense began as a home prototype for wheelchair users, with indoor tracking, reminders, appliance controls, and exercise suggestions. EaseAI extended it into a caregiver workflow prototype for nursing homes. I worked across embedded sensing, firmware, mobile, and backend.  
[Engineering case study ↗](https://nnoppons.github.io/wheelsense/) · [Source code ↗](https://github.com/NnopponS/WheelSense_Project)

**02 / WheelAthlete** · Research instrumentation  
Synchronized left and right wheel IMUs feed a Windows workflow for recording wheelchair motion, checking data quality, and exporting datasets. Acquisition stays separate from the desktop interface, so live recording does not depend on charts or analysis.  
[Engineering case study ↗](https://nnoppons.github.io/wheelathlete/) · [Source code ↗](https://github.com/NnopponS/WheelAthelse) · [Releases ↗](https://github.com/NnopponS/WheelAthelse/releases)

**03 / Indoor motion tracking** · First-author research  
At Thammasat University's CED2 research center, I compared machine learning and large language models for indoor motion tracking using Bluetooth Low Energy signal data. The work received Best Paper at ECTI-CON 2026.  
[Read the IEEE paper ↗](https://ieeexplore.ieee.org/document/11608653) · [Best Paper certificate preview ↗](https://nnoppons.github.io/evidence/#ecticon-best-paper-cert)
